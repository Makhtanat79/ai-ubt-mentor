# AI ҰБТ Mentor 4.0 — жеке есептік жазба

Тіркелу мен кіру қосылды. Теория қонаққа ашық; тест, нәтиже және жоспар үшін кіру қажет. Қолданбаны бұрынғы командамен қайта іске қосыңыз. Алғаш кіргенде «Тест тапсыру» → «Тіркелу» таңдаңыз. Пайдаланушы атын, сыныбын және кемінде 12 таңбалы құпиясөзді енгізіңіз. Аты-жөніңіз, телефон, email қажет емес.

Маңызды: бұрынғы оқушы коды мен жаңа аккаунт бөлек. Ескі нәтижелер базаға сақталған, бірақ жаңа аккаунтқа автоматты қосылмайды. Жүйеден шыққанда жеке тест күйі тазарады. Құпиясөзді қалпына келтіру әзірге жоқ; таңдалған тіркесті өзіңізде қауіпсіз сақтаңыз.

Интернетке жариялау әлі орындалмады. Тұрақты дерек сақтайтын хостинг керек; [жариялау нұсқаулығын](DEPLOY.md) қараңыз. Google Sheets синхрондауы және мұғалім кабинеті әзірге жоқ. 15 автоматты тест өтті; хостинг пен телефоннан толық тексеру орындалған жоқ.

## Оқу платформасының орнату нұсқаулығы

Қазақ тіліндегі информатикадан дайындық платформасы. 10–11-сыныптарға арналған авторлық оқу материалы. Python + Streamlit; ақылы API және сыртқы тілдік модель жоқ.

## Бұрын платформаны іске қосқан болсаңыз

Сол жоба қалтасындағы файлдар жаңартылды. Терминалда платформа жұмыс істеп тұрса, **Control + C** басыңыз. Содан кейін сол қалтада:

```bash
python3 -m streamlit run app.py --server.address 127.0.0.1
```

[http://localhost:8501](http://localhost:8501) бетін ашып, **Command + R** басыңыз. Сол жақта «Теория және тараулық тест» және «ҰБТ-ға дайындық: 25 нұсқа» бөлімдері болуы керек. Басты бетте **13 тарау / 620 тапсырма / 25 нұсқа** көрсетіледі. Терминалды қолданба жұмыс істегенше ашық қалдырыңыз.

ZIP-тен басқа қалтаға көшірсеңіз, ескі нәтижелерді көшіру үшін екі серверді де тоқтатып, бұрынғы `data/mentor.db` файлын жаңа қалтаның `data/mentor.db` орнына көшіріңіз. Мақсатты базада нәтиже бар болса, алдымен оның да көшірмесін алыңыз. Ескі базаны жоймаңыз. Жаңарту бастапқы нәтижелер пішімін оқи алады; база құрылымын өзгертпейді.

## Алғаш орнату (MacBook)

Python 3.11 немесе жаңасы қажет. Терминалға `cd ` деп жазып, жоба папкасын Finder-ден Терминалға сүйреңіз де, Enter басыңыз. Содан кейін командаларды бір-бірлеп орындаңыз:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

Алғаш орнатуға интернет керек; орнатылған бағдарлама мен оқу материалдары жергілікті жұмыс істейді. Браузер автоматты ашылмаса, [localhost:8501](http://localhost:8501) ашыңыз. Тоқтату — Control + C. Келесі жолы сол папкада ортаны `source .venv/bin/activate` арқылы белсендіріп, соңғы команданы қайталаңыз. Порт бос болмаса, `--server.port 8502` қосып, браузерде 8502 портын ашыңыз.

Windows-та `python3` орнына `python`, орта белсендіру үшін `.venv\Scripts\Activate.ps1` қолданылады.

## Не қосылды?

- **Теория және тараулық тест:** 13 тараудың әрқайсысында теория, шешілген мысал, жиі жіберілетін қате және өзіндік тексеру нұсқауы бар.
- Әр тараудың соңында **40 тапсырма:** 25 дара жауапты, бір мәнмәтіннің 5 сұрағы, 5 көп жауапты, 5 сәйкестендіру. Ең көбі 50 оқу ұпайы.
- **Тест тапсыру:** әдепкіде 40 тапсырма / 50 ұпайлық толық тест. «Қысқа жаттығу» бөлек режимінде 4, 8, 16 не 25 дара жауапты тапсырма таңдалады.
- **25 тұрақты нұсқа:** әрқайсысында 40 тапсырма. Бір нұсқаны қайта таңдағанда құрамы өзгермейді.
- Жауаптардың түсіндірмесі, қатесі бар тақырыптар және теорияны қайталауға өту.
- Бұрынғы және жаңа нәтижелердің тарихы, CSV жүктеу және TXT жоспар жүктеу.

## Дайындық жолы

1. Оқушы кодын енгізіңіз. Аты-жөнін жазудың қажеті жоқ.
2. «Теория және тараулық тест» ішінен тарауды таңдаңыз.
3. Теорияны оқып, мысалды қарамай қайта шығарыңыз.
4. «Осы тараудың тестін бастау» батырмасын басыңыз.
5. Дара тапсырмада бір жауап, көп жауаптыда барлық дұрыс нұсқа, сәйкестендіруде әр сол жақ ұғымға бір нұсқа таңдаңыз.
6. «Тестті аяқтау» басыңыз. Бос тапсырма болса, оның нөмірі көрсетіледі; толық емес тест базаға жазылмайды.
7. Қате жауаптарды ашып, түсіндірмесін оқыңыз. Теорияға оралып, қайта орындаңыз.
8. Тарауларды меңгерген соң 25 дайындық нұсқасын орындаңыз.

Бөлімдерді ауыстырғанда белсенді тест сессияда сақталады. Жаңа тест бастау аяқталмаған тестті ауыстырады. Браузерді толық жаңарту аяқталмаған тестті жоғалтуы мүмкін. Аяқталған нәтижелер SQLite базасында тұрақты сақталады. Оқушы кодын ауыстыру белсенді тестті тазартады.

## 620 тапсырма және 25 нұсқа қалай құрылған?

Қорда 325 дара жауапты, 65 көп жауапты, 65 сәйкестендіру және 33 мәнмәтінге байланысты 165 сұрақ бар: барлығы 620. Тараулық мәнмәтіндер әр тақырыптың өз мазмұнына сай берілген. Аралас 25 нұсқаның мәнмәтіндері SQL кестесі, Python тізімі, сурет көлемі, электрондық кесте және желі жылдамдығы бойынша бес есеп моделіне сүйенеді. Әр модельге бес дерек жиыны берілген.

Әр нұсқа: **25 дара жауапты + бір мәнмәтінге 5 сұрақ + 5 көп жауапты + 5 сәйкестендіру = 40 тапсырма.** Дара жауапты бөлікте 13 тараудың бәрі қамтылады. Нұсқалар ортақ қордан құралады; нұсқалар арасында сұрақтар қайталанады. Бұл 1000 бірегей сұрақ емес. Тұрақты тізімдер `variants.json` файлында сақталған.

## Тіл

Интерфейс мәтіндері, теория, тапсырма шарттары және түсіндірмелер қазақша жазылды. Python және SQL командалары, True/False, HTML атрибуттары мен электрондық кесте функциялары — оқытылатын тілдердің нақты синтаксисі, сондықтан аударылмайды. Кестелік функциялардың халықаралық атаулары қолданылды; редактор тілінде атауы өзгеше болуы мүмкін. Браузердің, операциялық жүйенің және Streamlit-тің кейбір жүйелік мәзірлері оның тіл баптауына тәуелді.

## Оқу бағалауы

Дара жауапты және мәнмәтін тапсырмасының толық дұрыс жауабы — 1 оқу ұпайы. Көп жауапты тапсырмада дұрыс жауаптар жиыны дәл сәйкес болса — 2, сәйкестендіруде барлық жұп дұрыс болса — 2; басқа жағдайда 0. Артық таңдалған жауап та қате саналады. Көп жауаптың таңдалу реті маңызды емес. Сәйкестендірудің жұптар реті маңызды.

Толық нұсқа ең көбі 50 оқу ұпайын береді. **Ресми ҰБТ-ның ішінара бағалау ережесі іске асырылмаған.** Нәтиже — жаттығу көрсеткіші; ол ҰБТ балын болжамайды. Ресми A/B/C қиындық үлестеріне сәйкестік расталмаған. Уақыт шектеуі енгізілмеген.

## Мазмұн негізі

Тақырыптық бағыттар мен тапсырма түрлерінің құрылымы [Ұлттық тестілеу орталығының информатикадан 2026 жылдан қолданылатын спецификациясы](https://testcenter.kz/wp-content/uploads/2025/10/28_%D0%98%D0%BD%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B0_%D0%BA%D0%B0%D0%B7.pdf) бойынша бағдарланған. Теория мен сұрақтар авторлық түрде жазылған; ресми тест тапсырмалары көшірілмеген. Спецификациядағы бағыттың болуы оның барлық ішкі тақырыбы толық әрі бірдей тереңдікте ашылғанын білдірмейді. Бұл — кеңейтілген оқу прототипі, ресми толық курс емес. Сыныпта қолданар алдында мұғалімнің мазмұндық шолуы ұсынылады.

## Жоспар

Ережелік алгоритм соңғы тесттегі тақырыптарды дұрыс орындалған тапсырмалар үлесі бойынша сұрыптап, жеті күндік жоспар жасайды. Тең үлестерде тесттегі рет сақталады. Тақырыптар жетіден аз болса, кезекпен қайталанады; жетіден көп болса, алғашқы жеті әлсіз тақырып беріледі. Қамтылмаған тақырыпқа баға берілмейді. Күндік уақыт — 15–60 минут. Бұл генеративті AI емес.

## Файлдар

- `app.py` — интерфейс және оқушы әрекеттері.
- `mentor_core.py` — бағалау, SQLite және жоспар логикасы; `core.py` — бұрынғы импорттармен үйлесімділік.
- `chapters.json` — 13 тараудың теориясы.
- `questions.json` — 620 тапсырма мен жауаптар.
- `chapter_tests.json` — 13 тараулық тесттің 40 тапсырмадан тұратын құрамы.
- `variants.json` — 25 нұсқаның тұрақты құрамы.
- `test_app.py` — автоматты тексерулер.
- `requirements.txt`, `.streamlit/config.toml` — тәуелділік пен көрініс.
- `data/mentor.db` — жергілікті база; ZIP-ке жеке деректер енгізілмейді.
- `QUALITY.md` — тексеру нәтижелері мен шектеулер.

Әр сұрақтың `id` мәні бірегей. `type`: `single`, `context`, `multi` немесе `match`. Дара жауапта `answer` — нөлден басталатын нұсқа индексі. Көп жауапта — индекстер тізімі; сәйкестендіруде — `left` элементтерінің ретімен дұрыс индекстер тізімі. Қорды өңдегеннен кейін төмендегі тесттерді қайта орындаңыз және `variants.json` сілтемелерін тексеріңіз. Ескі нәтижеде сұрақ көшірмесі сақталатындықтан, кейінгі өзгеріс бұрынғы нәтижені қайта бағаламайды.

## Тексеру

Жоба папкасында:

```bash
python3 -m unittest -v
```

13 автоматты тест сәтті өтті. Бағалау, 25 нұсқаның құрамы, мәнмәтін есептеулері, жарамсыз/бос/жартылай жауаптар, сақталу, бұрынғы нәтижелермен үйлесімділік және интерфейстің негізгі жолдары тексерілді. Тесттер уақытша база қолданады. `missing ScriptRunContext` ескертуі AppTest режиміне тән.

Браузердің тірі беті осы ортада қолжетімсіз болды; визуалды көрініс, телефон экраны және пернетақтамен толық өту тексерілмеген. Негізгі интерфейс сценарийлері Streamlit AppTest арқылы тексерілді. Python 3.14.7 / Streamlit 1.63.0 қолданылды.

## Деректер

Нәтижелер енді жүйеге кірген аккаунт идентификаторымен сақталады. Пайдаланушы аты басқа оқушының тарихын ашуға қолданылмайды. Жаңа жазбалар, сессиялар және нәтижелер бір SQLite базасында сақталады; дерекқор файлын жалпыға таратпаңыз. Сыныпта нақты аты-жөнінің орнына бүркеншік ат қолдануға болады.

## 3.0 жаңартуы (2026-11-14)

Тараулық тесттер де 40 тапсырма / 50 оқу ұпайына жеткізілді. Қор 620 тапсырмаға кеңейді, оның бір бөлігі сандық параметрлері өзгертілген жаттығулар. Деректер базасы мен HTML тараулары анық атаулармен беріліп, теориясы код мысалдарымен толықтырылды. 25 аралас нұсқа кеңейтілген қордан қайта құрастырылды; бұрынғы нәтижелер өзгермейді. Жаңа нұсқаларды бұрын орындалған нұсқалармен бірдей тест деп салыстырмаңыз. Мәзірдегі қаріпке тәуелді белгішенің орнына қазақша мәтін қойылды; нақты браузердегі көрініс тексерілмеген.
